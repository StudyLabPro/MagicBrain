# Security Policy

MagicBrain accepts responsible security reports for the frontend, backend,
simulation tools, APIs, deployment configuration, documentation examples, and
related ecosystem integrations.

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.

Send private reports to `uwt@xteam.pro` with the subject:
`[SECURITY][MagicBrain] Brief description`.

Include:

- affected component and version or commit;
- reproduction steps;
- expected and actual impact;
- proof of concept, screenshots, or logs if safe to share;
- suggested fix, if available.

Do not include secrets, private user data, or exploit payloads that are not
required to validate the issue.
